# WP Status Saver

A lightweight, native Android application for saving and managing WhatsApp and WhatsApp Business status updates.

## Getting Started

### Prerequisites
- Android Studio Ladybug or newer
- JDK 17 / Android Studio JBR
- Android SDK 35 (Minimum SDK 23 / Android 6.0+)

### Building from Source

1. Clone this repository:
   ```bash
   git clone https://github.com/theonlyasdk/WPStatusSaver.git
   ```
2. Open the project in Android Studio.
3. Build the project with Gradle:
   ```bash
   ./gradlew assembleDebug
   ```

## Tech Stack
- **Language:** Kotlin
- **Architecture:** Android Jetpack (ViewBinding, Coroutines, Lifecycle)
- **UI Components:** Material Components, PhotoView, SwipeRefreshLayout
- **Media Loading:** Glide
